# Civic Legal AI

Initial repository for a hackathon project in the legal and civic AI space.

## Current status

This repository is only a starting workspace. The team has **not yet decided**:

- the exact problem statement or target users
- the product features
- the technology stack
- the system architecture
- the AI models, APIs, or datasets
- deployment and hosting
- team ownership and development workflow

Those decisions will be made together during project planning.

## Initial structure

- `frontend/` — future user-facing application work
- `backend/` — future server-side and API work
- `ai/` — future AI, retrieval, or model-related work
- `data/` — future dataset notes and data work
- `docs/` — future planning and documentation

Each folder currently contains only a short placeholder. Implementation files and framework-specific configuration should be added after the team agrees on the project direction.

## Next step

Hold an initial planning session and document the agreed problem, users, scope, responsibilities, and technology choices before implementation begins.
